# Audit Pup

Audit Pup (El Dorado Tax-Aide Case Checker) checks a counselor's TaxSlayer training PDF for one step of a case against that case's answer key. It shows which lines are correct, gives a hint with the answer key value for each line that needs another look, and celebrates with a random dog when everything is done.

**Use it here:** https://jaycarterwells.github.io/audit-pup/

## How to use

1. Pick the case and the step you are checking.
2. Drop in the PDF you printed from TaxSlayer after finishing that step.
3. Fix anything flagged, print a new PDF, and check again.

Everything runs in your browser. Nothing is uploaded. Your progress is saved in your browser on your computer.

Using a Chromebook? See the one-page [Chromebook guide for counselors](docs/chromebook-guide.md).

## Versions

The current version and what changed in each one are shown by the Version button at the top of the page. Each release is tagged in this repository (for example `v0.11.0`), following semantic versioning.

## Notes

* All case data is fabricated training data from the TaxSlayer Practice Lab. No real taxpayer information is included.
* Works in Chrome (including Chromebooks) and in Safari 15 or newer.
